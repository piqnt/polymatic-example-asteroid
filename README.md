# Asteroid Game - Polymatic Example

Implemented using [Polymatic](https://github.com/piqnt/polymatic) framework, [Planck.js](https://github.com/piqnt/planck.js) physics engine and [Pixi.js](https://pixijs.com/) rendering engine.

[Play Live Demo](https://piqnt.github.io/polymatic-example-asteroid/)

Use arrow keys to turn and thrust, and space to fire.

### How to run the code

To run or build the source code in this repository you need to have node.js/npm installed.

Install this project dependencies:

```sh
npm install
```

To run the project locally:

```sh
npm run dev
```

This will print out the url where you can open the project.

To build the project for production:

```sh
npm run build
```
